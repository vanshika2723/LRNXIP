# Learnix Week 1 Landing Page

A responsive internship landing page made with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive navigation with mobile menu
- Hero section: Learn • Build • Perform • Grow
- Six internship tracks: Full Stack, AI/ML, Data Science, Cloud, Java, and Python
- Developer portfolio/about section
- Contact form with client-side validation
- Responsive layout and reduced-motion support

## Run locally
Open `index.html` in your browser. No build step is required.

## Important
The contact form validates inputs in the browser only. To receive real submissions, connect a backend or a form service.
